Flare Fireplace Quotes v1.6.7

Fireplace locations:
- Each fireplace can have its own optional name or location, such as Living Room, Primary Bedroom, or Patio.
- The location stays with that fireplace when it is added, edited, reordered, priced, recalled, or sent through URL verification.
- Quote previews, PDF pages, URL-review cards, and Gmail spec-link headings identify the matching fireplace location.
- Fireplaces without a location keep the existing model-based wording for backward compatibility.

Cleanup:
- Prior build folders, archived installers, old portable packages, and generated release manifests are excluded from the 1.6.7 deliverables.
- The release set contains only the current updater installer, portable application archive, and verified update manifest.
