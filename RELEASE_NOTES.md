Flare Fireplace Quotes v1.6.0 introduces the refreshed three-pane quote workspace while preserving the audited pricing, PDF, Gmail, updater, security, and model-mapping systems.

- Moves the workflow stepper into the title bar and removes the separate workflow header band.
- Presents Customer Request, the current-fireplace builder, and Fireplaces on This Quote together in a modern three-pane workspace.
- Adds editable fireplace summary cards with lead-time, feature, classic-media, and premium-media details.
- Keeps a fireplace safely on the quote while it is edited; Save Changes replaces it in place, and canceling an edit preserves the original.
- Adds a guarded burn-away removal animation that cannot block the underlying remove command.
- Adds readiness, fireplace-count, and estimate status without allowing stale priced totals to remain after quote changes.
- Adds an in-app manual update check and keeps verified installation in the existing trusted startup updater flow.
- Updates the Windows UI snapshot gate for the new three-pane geometry and retains minimum-window validation.
- Keeps the official pricing workbook, resource workbooks, 302-model inventory, parsing, feature/media catalogs, PDF generation, Gmail drafting, DPAPI storage, redacted logging, updater signature/trust policy, and professional release pipeline unchanged.
